# stock-app

スマホで見る株式市場アプリ「株マーケット」の画面です。ホーム画面に追加して使う Web アプリ(PWA)です。

- このリポジトリには画面の部品だけを置き、データは含みません。
- データは非公開のリポジトリから、利用者が設定した読み取り専用の鍵で読み込みます。

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組み |
| app.css | 見た目(上昇は赤、下落は青) |
| app.js | データの読み込みと4つのタブ(朝・夜・注目・予定)の表示 |
| manifest.webmanifest | ホーム画面に追加したときの名前とアイコン |
| sw.js | 画面の部品を端末に保存する仕組み。画面を直したら VERSION を上げる |
| icons/ | アイコン(tools/make_icons.py で作成) |
